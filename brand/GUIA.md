# Identidad visual de SYSVARK

**SYSVARK** se pronuncia *Sis-vark*. El nombre recoge Systems, Architecture y una referencia a Álvaro Sánchez Pérez, fundador del proyecto en España. El descriptor internacional es **Business Automation & Software**. En comunicación corporativa se utiliza el eslogan **Sistemas conectados. Negocios eficientes.**

## Símbolo y firmas

El isotipo reúne tres trazos escalonados con cortes en diagonal. Las bandas evocan los niveles de una arquitectura de software y el movimiento de registros entre sistemas. La forma encaja en un módulo cuadrado para utilizarse en avatares o en la pestaña del navegador.

| Aplicación | Archivo |
| --- | --- |
| Presentación corporativa vertical con descriptor | `brand/logo-principal.svg` |
| Navegación o firma sobre fondo claro | `assets/wordmark.svg` |
| Firma horizontal sobre azul petróleo o negro | `brand/logo-horizontal-dark.svg` |
| Impresión a una tinta | `brand/logo-mono.svg` |
| Símbolo independiente | `brand/isotipo.svg` |
| Favicon | `assets/favicon.svg`, `assets/favicon-32.png` |
| Perfil de GitHub y perfil de correo | `brand/perfil-github.png`, `brand/perfil-correo.png` |
| Tarjeta social y Open Graph, 1200 × 630 | `brand/social.svg`, `brand/portada-social.png`, `assets/og.png` |

Los archivos PNG complementan los originales SVG. Conserva la proporción y deja aire alrededor equivalente a la altura de una banda del símbolo. Para tamaños menores de 96 px de ancho, utiliza el isotipo. Sitúa las firmas sobre fondos lisos con contraste. En recursos nuevos, conserva las diagonales y la separación de las tres bandas.

## Color

| Color | Valor sRGB | Uso |
| --- | --- | --- |
| Blanco roto | `#FAFAF8` | Fondo principal |
| Casi negro | `#171717` | Texto y jerarquía editorial |
| Azul petróleo | `#203D48` | Logotipo, acciones principales y calculadora |
| Azul suave | `#91B2BE` | Superficies gráficas y conexiones del diagrama |

El azul suave funciona como elemento gráfico. En texto sobre superficie clara utiliza petróleo, casi negro o el color secundario de texto `#4E6066`.

## Tipografía y composición

La web utiliza **Segoe UI**, con Arial y Helvetica de reserva, servidas por el sistema del visitante. Los diagramas y etiquetas técnicas emplean Consolas o la fuente monoespaciada local. En el logotipo se usa Arial Bold con espaciado ajustado. El titular de portada tiene un interlineado compacto; los párrafos utilizan un interlineado de 1,55 a 1,6. Mantén una única acción principal por grupo.
